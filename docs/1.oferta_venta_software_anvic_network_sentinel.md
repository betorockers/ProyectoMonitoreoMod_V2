# Oferta de Venta de Software
## Anvic Network Sentinel

## Documento Ejecutivo-Commercial

## 1. Presentacion

Anvic Network Sentinel es una plataforma de supervision tecnica y visual orientada a instalaciones de seguridad, control de acceso, CCTV y entornos operacionales donde la continuidad del servicio es critica.

El software fue concebido para responder a necesidades reales de monitoreo, diagnostico y soporte en terreno. Su valor no esta solamente en "ver si un equipo responde", sino en permitir una gestion mas estructurada de disponibilidad, soporte, evidencia y supervision remota.

En el contexto de ANVIC, Sentinel se posiciona como una pieza natural dentro de una oferta de:

- monitoreo de instalaciones en tiempo real
- mantenimiento preventivo y correctivo
- supervision de CCTV
- control operacional de sistemas de acceso
- soporte tecnico con evidencia

## 2. Propuesta de Valor del Software

Anvic Network Sentinel permite consolidar en una sola plataforma:

- monitoreo de disponibilidad por IP
- historial de eventos y continuidad operacional
- diagnostico tecnico integrado
- chequeos HTTP/HTTPS
- escaneo de puertos controlado
- SNMP basico
- SSH orientado a consulta
- supervision visual de camaras mediante snapshot y pruebas de stream
- gestion de usuarios
- configuracion y politicas operativas

Su fuerza comercial esta en que combina valor tecnico con una aplicacion directa al negocio de ANVIC, especialmente en:

- CCTV
- control de acceso
- monitoreo remoto
- continuidad de instalaciones
- mantenimiento preventivo

## 3. Integracion con los Servicios de ANVIC

Sentinel puede integrarse como capa de soporte y monitoreo dentro de los servicios actuales de ANVIC:

- diseno y estructura de centrales de CCTV
- puesta en marcha y operacion
- estudios de seguridad de instalaciones
- implementacion de medidas de seguridad tecnologicas
- reparacion y mantenimiento preventivo de alarmas y CCTV
- monitoreo de instalaciones en tiempo real

### Ejemplos de encaje

#### CCTV

- validacion de conectividad de camaras y equipos asociados
- chequeo de interfaz web y servicios expuestos
- supervision visual por snapshot y video progresivo

#### Control de acceso

- monitoreo de totems, barreras, kioskos y equipos IP asociados
- seguimiento de disponibilidad operacional
- apoyo al soporte tecnico y continuidad del servicio

#### Monitoreo tecnico de instalaciones

- monitoreo de equipamiento critico por instalacion
- evidencia historica y operacional
- reduccion de tiempos de diagnostico

## 5. Ediciones Comerciales Recomendadas

Para facilitar su venta, posicionamiento y licenciamiento, se recomiendan tres ediciones:

### 5.1 Sentinel Standard

Enfoque:

- monitoreo base y visibilidad operacional

Incluye:

- monitoreo por IP
- dashboard de estado
- historial operacional
- reportes base
- control de usuarios
- soporte de multiples equipos
- funciones base de supervision

Perfil comercial:

- instalaciones pequenas
- clientes con necesidad de monitoreo esencial
- adopcion inicial

### 5.2 Sentinel Advanced

Enfoque:

- monitoreo tecnico ampliado y soporte integrado

Incluye todo Standard, mas:

- chequeos HTTP/HTTPS
- escaneo de puertos controlado
- SNMP basico
- SSH orientado a consulta
- Centro de Soporte
- supervision visual base
- configuracion operativa ampliada
- politicas TLS

Perfil comercial:

- instalaciones medianas
- clientes con mayor criticidad operacional
- uso tecnico mas intensivo

### 5.3 Sentinel Pro

Enfoque:

- plataforma de operacion, supervision visual y explotacion comercial mas robusta

Incluye todo Advanced, mas:

- supervision visual avanzada
- flujo preparado para video en vivo
- control de streams simultaneos
- enfoque multi-instalacion
- capacidad de estructurarse como plataforma de servicio
- acompanamiento comercial/tecnico mas fuerte

Perfil comercial:

- clientes corporativos
- instalaciones criticas
- uso como base para servicios gestionados

## 8. Formas de Ofrecer el Software

El producto puede ofrecerse de distintas maneras segun la estrategia de negocio:

### Modalidad 1: Licencia por equipo

La forma mas basica.

Ideal para:

- pilotos
- proyectos pequenos
- casos donde se quiera minimizar entrada inicial

### Modalidad 2: Licencia por instalacion

Mas clara para cliente final.

Ideal para:

- control de acceso
- CCTV
- instalaciones con varios activos IP

### Modalidad 3: Licencia corporativa interna

Ideal para:

- ANVIC como operador
- despliegue transversal
- uso en multiples contratos o instalaciones bajo control de la empresa

### Modalidad 4: Licencia corporativa con derecho a ofrecer servicio

La modalidad con mayor potencial estrategico.

Ideal para:

- integrar Sentinel dentro de la oferta formal de servicios ANVIC
- vender monitoreo, soporte y supervision como servicio recurrente
